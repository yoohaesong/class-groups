# 우리 반 모둠 나누기 (Class Groups)

출석번호 기반의 스마트 무작위 모둠 배정 웹 애플리케이션입니다.

## ✨ 주요 기능
- **간편한 출석 관리**: 총 학생 수 입력 및 원클릭 결석생 제외
- **유연한 모둠 구성**: '모둠 수 기준' 및 '모둠당 인원수 기준' 지원
- **스마트 배정 옵션**: 모둠장 1명씩 우선 분배 및 특정 학생 쌍 같은 조 방지
- **발표 연출**: 두근두근 순차 추첨 모드 및 즉시 발표 모드
- **효과음 & 컨페티**: Web Audio API 기반 오프라인 사운드 및 축하 폭죽 효과
- **수업 편의**: 마우스 드래그 앤 드롭 자리 이동, 결과 텍스트 복사, 빔프로젝터 전체화면 모드
- **오프라인 동작**: 외부 라이브러리 및 의존성 없는 단일 HTML 파일
